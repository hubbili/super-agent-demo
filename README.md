# Super Agent Demo

用于体验 DSH Superagent 的 GitHub 任务接收、代码修改和 Pull Request 流程。

## 体验流程

按以下四步体验一次完整的自动化协作：

| 步骤 | 说明 |
| --- | --- |
| **创建 Issue** | 在本仓库新建 Issue，在正文中 `@flea-wu` 说明需要修改的内容。标题和正文请写清目标与范围，Issue 会作为任务的来源。 |
| **执行任务** | Superagent 接单后阅读需求与仓库上下文，在自己的分支上完成代码修改并做必要验证，不会直接改动 `main` 分支。 |
| **提交 PR** | 完成后向仓库提交 Pull Request，附上改动说明和验证结果，并关联对应的 Issue。 |
| **人工评审** | 由人检查 PR 中的改动与说明，确认无误后合并；如有问题，在 PR 中留言即可继续迭代。 |

完成后可以从第一步开始，体验下一个任务。
